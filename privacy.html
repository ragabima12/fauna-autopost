Privacy Policy

Last updated: 27 November 2026

Fauna in 60 Autopost ("the tool") is a private tool used only by the owner of the YouTube channel Fauna in 60 to upload and schedule videos on that channel. It is not offered to the public.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

With the owner's permission, given through Google OAuth 2.0, the tool uses these scopes:

  • youtube.upload: upload videos and set thumbnails on the owner's channel.
  • youtube.force-ssl: post a comment on the owner's own videos and read the owner's own channel and uploads.

It reads only the owner's channel ID, title and list of uploaded videos with their privacy status. It does not access data of any other YouTube user or channel.

What is stored, and where

  • Video IDs, titles, scheduled publish times and upload status of the owner's own videos, in a local file on the owner's computer.
  • The OAuth access and refresh token, in a local file readable only by the owner's account.

Nothing is stored on a server. No cookies, analytics or tracking are used.

Sharing

No data is sold, shared, or sent anywhere except to YouTube itself through the YouTube API Services.

Keeping data current, and deleting it

  • Stored video status is refreshed from YouTube each time the tool runs, and it is never kept longer than 30 days without being refreshed or deleted.
  • To revoke the tool's access, open Google Account permissions (Security settings) and remove "Fauna in 60 Autopost".
  • After access is revoked, or on request, the local token and all stored data are deleted within 7 days.
  • To ask for deletion, email the contact below.
