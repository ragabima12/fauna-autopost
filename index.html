Fauna in 60 Autopost

A private command-line tool that schedules Shorts for one YouTube channel, Fauna in 60, owned and run by the same person who built the tool.

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Read how data is handled in the Privacy Policy.

What it does

  • Uploads a finished Short to the owner's channel as private, with a scheduled publish time (one per day).
  • Sets the custom thumbnail the owner designed.
  • After the Short goes public, posts one comment from the channel on that Short.
  • Lists the channel's own uploads to avoid uploading the same video twice.

Who can use it

Only the channel owner. It runs on the owner's computer, it is not distributed, and it has no public sign-up. It signs in with Google OAuth 2.0 and can be disconnected at any time at Google Account permissions.
