Fauna in 60 Autopost — Privacy Policy

Last updated: 27 November 2026

Fauna in 60 Autopost is a private tool used only by the owner of the YouTube channel Fauna in 60 to upload and schedule videos to that channel. It is not offered to the public.

What it accesses

With the owner's permission (Google OAuth), the tool uses the YouTube API Services to upload videos, set thumbnails, post comments on the owner's own videos, and list the owner's own uploads.

What it stores

Video IDs and upload status, saved in a local file on the owner's computer. The login token is stored on the same computer and is never shared. No data from other YouTube users is collected.

Sharing

No data is sold, shared or sent anywhere except to YouTube itself.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be removed at any time at Google Account permissions.
